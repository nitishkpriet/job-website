# CareerPath — Job & Career Recommendation Portal

A responsive, multi-page career portal that helps users explore job opportunities, select skills, discover course recommendations, and track learning progress.

## ✨ Features

- **Job Listings:** Browse the job listings page.
- **Skill Selection:** Select and save skills in the browser.
- **Job Recommendations:** View sample job suggestions based on selected skills.
- **Course Recommendations:** Explore predefined course suggestions based on selected skills.
- **User Dashboard:** View skills, jobs, courses, and progress-related information.
- **Progress Tracking:** Simulate course progress and view completion indicators.
- **Login & Signup Forms:** Client-side required-field validation and password confirmation.
- **Responsive Design:** Layouts adapt to desktop, tablet, and mobile screens.
- **Mobile Navigation:** Toggle the navigation menu on smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## 🚀 Getting Started

### Prerequisites

A modern web browser. No package installation is required for the basic frontend.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/nitishkpriet/job-website.git
   ```

2. Open the project folder.
3. Open `job/index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code to run the website locally.

## 📝 Notes

- Job and course recommendations currently use predefined sample data in JavaScript.
- Selected skills are stored in browser localStorage.
- Login and signup validation is client-side; this project code does not establish that secure backend authentication is implemented.
